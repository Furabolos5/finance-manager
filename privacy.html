Privacy policy

Finance Manager, last updated 5 October 2026.

What the app does

Finance Manager is a personal finance tracker used by its author. It stores financial records (accounts, transactions, budgets, investments) on the user's own Windows PC and Android phone.

Google Drive access

To keep the two devices in step, the app asks for the Google Drive scope drive.file. This lets the app see and edit only the files it creates itself, in a folder named FinanceManagerSync. It cannot see any other file in the user's Drive.

What is collected and shared

The developer does not receive, collect, store or have access to any user data. There is no server operated by the developer. Data moves only between the user's own devices and the user's own Google Drive. It is not sold, shared with third parties, or used for advertising.

Third-party services

The app may request public exchange rates (European Central Bank) and public security prices. These requests do not include any personal or account information.

Deleting data

The user can delete all data by uninstalling the app and deleting the FinanceManagerSync folder from Google Drive. Access can also be revoked at any time at myaccount.google.com/permissions.
